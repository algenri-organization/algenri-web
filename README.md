# ALGENRI Web

Site institucional oficial da ALGENRI.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Lucide React

## Estrutura inicial

- `/` — Home
- `/solucoes` — portfólio de soluções
- `/planos` — planos de evolução digital
- `/diagnostico` — Diagnóstico Digital ALGENRI
- `/contato` — canais de contato

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

O workflow `ALGENRI Web CI` executa TypeScript e build do Next.js em pushes e pull requests para `main`.
